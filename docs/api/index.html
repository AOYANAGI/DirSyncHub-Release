required
uid
required
string non-empty

required
string non-empty

ユーザー検索

LDAPフィルターでユーザーを検索します（JWT必須）。

必要操作権限一覧

  • directory.search: ディレクトリの検索・取得を許可
Request Body schema: application/json
required
filter
required
string

LDAP フィルター文字列。例: "(&(objectClass=user)(sn=山田))"

sortBy
null or string

並び替え対象の属性名。未指定時はサーバー既定順を使用します。

sortDescending
boolean
Default: false

降順ソートを行うか。true で降順、false で昇順です。

additionalAttributes
Array of strings or null

標準項目に加えて返却したい LDAP 属性名一覧。

pageSize
null or integer or string <int32> ^-?(?:0|[1-9]\d*)$

1ページあたりの最大取得件数。未指定または 0 の場合はページングしません。

pageToken
null or string

前回レスポンスの nextPageToken。指定時は続きのページを取得します。

Responses

/api/dshub/v1/directory/users/search

Request samples

  • Payload
Content type
application/json
{
  • "filter": "(&(objectClass=user)(sn=*青柳*))",
  • "sortBy": "displayName",
  • "sortDescending": false,
  • "additionalAttributes": [
    • "mail",
    • "department"
    ],
  • "pageSize": 50,
  • "pageToken": null
}

Response samples

  • 200
Content type
application/json
{
  • "items": [
    • {
      • "distinguishedName": "CN=Masaki AOYANAGI,OU=Users,DC=example,DC=local",
      • "samAccountName": "masaki.aoyanagi",
      • "displayName": "Masaki AOYANAGI",
      • "mail": "masaki.aoyanagi@example.local",
      • "department": "IT"
      }
    ],
  • "nextPageToken": null
}

自然言語検索

自然言語クエリをLDAPフィルターへ変換して検索します（JWT必須）。

必要操作権限一覧

  • directory.search: ディレクトリの検索・取得を許可
Request Body schema: application/json
required
query
required
string

自然言語の検索文。例: "無効ユーザーを50件表示"

sortBy
null or string

並び替え対象の属性名。指定時は自然言語解析結果より優先されます。未指定時は解析結果または既定値を使用します。

sortDescending
boolean
Default: false

降順ソートを行うか。SortBy を明示した場合に有効です。

additionalAttributes
Array of strings or null

標準項目に加えて返却したい LDAP 属性名一覧。例: ["mail", "department"]

pageSize
null or integer or string <int32> ^-?(?:0|[1-9]\d*)$

1ページあたりの最大取得件数。未指定または 0 の場合はページングしません。

pageToken
null or string

前回レスポンスの nextPageToken。指定時は続きのページを取得します。

Responses

/api/dshub/v1/directory/search/nl

Request samples

  • "pageToken": null
}
